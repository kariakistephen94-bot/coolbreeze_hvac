# Helio — solar company frontend

A responsive concept website made with HTML, CSS, and JavaScript. Open `index.html` directly, or serve this folder with a static web server.

- `index.html`: page content and original inline rooftop illustration.
- `styles.css`: responsive layout and visual styling.
- `script.js`: chatbot modal, service selection, and contact form preview.

The bottom-left chatbot opens as a modal, closes with its close button, Escape, or an outside click, and contains a disabled message field. No chat service is connected. The contact form validates input locally but does not send or save details. Helio is illustrative branding. Google Fonts is optional; local fallback fonts are provided.
